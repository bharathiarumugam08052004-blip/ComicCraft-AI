# ComicCraft

ComicCraft is an AI-powered comic story creator.

## Features

- Story idea input
- AI story outline
- AI dialogue and narration
- Comic panel image generation
- Comic preview
- PDF export

## Run

Create virtual environment:

python -m venv .venv

Activate:

.venv\Scripts\activate

Install:

pip install -r requirements.txt

Run:

uvicorn app.main:app --reload

Open:

http://127.0.0.1:8000
